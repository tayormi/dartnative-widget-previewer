# Material Symbols Rounded

Google Material Symbols, Apache 2.0. The static font and 4229 codepoints match the DartNative 3.45.0-0.1.pre SDK used for native reference builds.

Font SHA-256: `ed1c0fe3fb7483259ae31c731bfe7211ff96f83a426d71b9c0996fe816dc8916`

Upstream: https://github.com/google/material-design-icons

The font is not substituted with a variable web font: weight, fill, glyph shapes and codepoints must match the native asset. SDK upgrades must regenerate the map and rerun visual comparisons.
